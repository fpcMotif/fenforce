---

Run commands from the repository root after installing dependencies with Bun. Use `bunx vite-plus run {package}#{task}` to run a package task.

## Starting the App

```bash
bunx vite-plus run twenty-front#start    # Frontend dev server (http://localhost:3001)
bunx vite-plus run twenty-server#start   # Backend server (http://localhost:3000)
bunx vite-plus run twenty-server#worker  # Background worker
```

## Database

```bash
bunx vite-plus run twenty-server#database:reset  # Reset and seed database
bunx vite-plus run twenty-server#database:migrate:prod  # Run migrations
bunx vite-plus run twenty-server#database:migrate:generate --name <name> --type <fast|slow>  # Generate a migration
```

## Linting

```bash
bunx vite-plus run twenty-front#lint:diff-with-main   # Lint changed files
bunx vite-plus run twenty-server#lint:diff-with-main
bunx vite-plus run twenty-front#lint:fix              # Auto-fix
```

## Type Checking

```bash
bunx vite-plus run twenty-front#typecheck
bunx vite-plus run twenty-server#typecheck
```

## Testing

```bash
# Frontend
bunx vite-plus run twenty-front#test              # Jest unit tests
bunx vite-plus run twenty-front#storybook:build   # Build Storybook
bunx vite-plus run twenty-front#storybook:test    # Storybook tests

# Backend
bunx vite-plus run twenty-server#test             # Unit tests
bunx vite-plus run twenty-server#test:integration  # Integration tests
bunx vite-plus run twenty-server#test:integration:with-db-reset  # Integration with DB reset

# Single file (fastest)
bunx jest path/to/test.test.ts --config=packages/{project}/jest.config.mjs
```

## GraphQL

```bash
bunx vite-plus run twenty-front#graphql:generate           # Regenerate types
bunx vite-plus run twenty-front#graphql:generate:metadata  # Metadata schema
```

## Translations

```bash
bunx vite-plus run twenty-front#lingui:extract   # Extract strings
bunx vite-plus run twenty-front#lingui:compile   # Compile translations
```

## Build

```bash
bunx vite-plus run twenty-shared#build   # Build shared output
bunx vite-plus run twenty-front#build
bunx vite-plus run twenty-server#build
```
