# Backend capability and acceptance map

## At a glance

Twenty's backend contains intertwined capabilities that a database replacement alone cannot preserve.
This map assigns proposed target responsibilities and acceptance checks to 25 capability groups.
Existing Twenty behavior remains the baseline, and all migration parity remains unverified.

## Evidence boundary

The audited fork revision is `1bf3ec682fcc7b768d1ea895d1a39ec917299b5c`.
The supplied upstream baseline is local ref `a431f9afb6e761322109ea3b1b942e007b31eef2`.
This inventory inspects the fork; it does not attribute every capability to upstream.

Every row has source evidence, but provider configuration and deployed behavior remain unverified.
Checks below are required acceptance cases, not recorded passing results.
Apply the [shared acceptance gates](criteria-map.md) to every row.
Target responsibilities describe proposed ownership, not implemented replacements.

## Hard mappings that remain unproven

1. Model workspace-specific schemas, SQL constraints, joins, indexes, and transactional merges in Convex.
2. Preserve generated GraphQL, REST, SDK, and MCP contracts while consumers migrate.
3. Place subprocesses, Lambda dependencies, arbitrary code, IMAP/SMTP connections, and streams in suitable runtimes.
4. Reconcile database state, object storage, queue acknowledgements, and provider effects without assuming one transaction.
5. Preserve the complete workflow catalog, version behavior, forms, cancellation, retries, and run history.
6. Match search ranking and cursor behavior currently expressed through PostgreSQL text-search concepts.
7. Verify conditional file promotion and cleanup races on the selected storage provider.
8. Propagate authorization through jobs, subscriptions, application actors, AI tools, and provider callbacks.

Effect does not replace database transactions or durable workflow persistence.
Cloudflare Workflows does not by itself establish exactly-once provider side effects.
The isolated approval experiment does not prove these mappings.
